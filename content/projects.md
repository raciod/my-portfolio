# Real Projects

Here are the tools I'm actively developing:

* **[AzN](https://github.com/raciod/AzN)** - Check out the repository for my AzN project.
* **[LAN-Mapper](https://github.com/raciod/LAN-Mapper)** - An automated network mapping and discovery utility.
* **[BIIID](https://github.com/raciod/BIIID)** - Linux kernel-level firewall module using Netfilter hooks and a user-space CLI manager over Netlink IPC.
* **[linux-server-bootstrap](https://github.com/raciod/linux-server-bootstrap)** - A Bash script that automatically locks down and sets up a fresh Linux server — configuring the firewall, securing SSH access, installing Docker, and keeping services running automatically. Safe to run multiple times without breaking anything.
